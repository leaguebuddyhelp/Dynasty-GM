# CUS03 early prospects

`/earlybigboard` includes all 32 ranked CUS03 preseason prospects. Rankings and scouting notes come from `bundled_data/madden/Madden - CUS03 - Early Big Board.json`, with 32 authored preseason bios in `early-top-10-bios.json`.

All 32 early-board prospects have transparent portraits. `class03-portrait-prompts.json` records the built-in imagegen prompts and image paths in current draft order. The early board matches portraits by name, school and position, with either edge designation matching the same player.

`/prospects` → **CUS03** → **QB** includes the nine quarterbacks from `bundled_data/madden/Madden - CUS03 - Big Board.json`. The cards use 40–50-word bios in `profiles.json` and display **Unranked** when the Big Board has no round and pick. Portrait prompts for the new quarterback images and Jake Denney’s updated portrait are in `big-board-qb-portrait-prompts.json`.
