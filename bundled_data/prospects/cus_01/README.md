# CUS01 prospect cards

Run `/prospects` in Discord, choose a position, then choose a player. The browser is private to the operator. There are 43 published profiles: six QBs, seven HBs, seven WRs, seven TEs, four LTs, two LGs, two centers, two RGs and six RTs. Offensive-line positions stay separate. Other positions remain available in the menu with an unpublished notice.

Player measurements, school, class year, jersey and board rank come from `bundled_data/madden/Madden - CUS01.json`. Archetype is only a writing guide and is omitted from cards and menus, along with overall ratings and development traits. The source school spelling `Minneosta` displays as Minnesota. This command does not change `/bigboard` or its file selection.

`profiles.json` holds authored scouting profiles, fictional college statistics and portrait filenames, keyed by source record ID. At the user's explicit request, college stat lines are invented and clearly labelled on each card. They are not EA imports, actual results or inputs to awards or progression. Bios focus on skills, production and growth areas, with stronger projections for higher board positions and narrower roles for later prospects. No injury histories were invented. Profiles must match the source name and have all seven appearance fields before publication. To add another position, complete its source appearance fields, add an editorial profile and save its portrait in `portraits/`.

Efficiency is calculated from the authored totals rather than entered separately: yards per route run is receiving yards divided by routes; rushing yards after contact per carry uses after-contact yards divided by carries; ANY/A is `(passing yards + 20 × TD − 45 × INT − sack yards) / (attempts + sacks)`. Catch rates and yards after catch per reception use their corresponding totals. TE and OL blocking profiles can include fictional run-block wins per assignment and pressures allowed per pass-block snap. OL pressure totals sum the authored sacks, hits and hurries, with penalties and offensive snaps shown separately. These fictional college metrics are descriptive scouting material, not measured Madden attributes or external analytics grades.

Portraits were generated with the built-in imagegen tool, using individual prompts recorded in `portrait-prompts.json`. Each is an independent fictional adult athlete, in the named school's branded jersey and colors. Background removal edits are recorded in `transparent-portrait-prompts.json`; cards use the resulting transparent PNG cutouts. Jaquon Hall's conflicting hair fields were resolved using the explicit `hair_color: black` value. Vague facial descriptions were interpreted naturally without inferring character or athletic ability from ethnicity or appearance.

HB, WR, TE and OL portraits were generated directly with alpha transparency using the prompts in `hb-portrait-prompts.json`, `wr-portrait-prompts.json`, `te-portrait-prompts.json` and `ol-portrait-prompts.json`. Colt Fisher's portrait follows the corrected white/fair skin, blue eyes and brown hair. Cards reuse supplied school emoji IDs where available; schools without a supplied emoji use a text label and school color.

The assets are bundled with the bot and attached directly to Discord cards. There are no runtime AI requests or new API keys required. When deploying, register the `/prospects` command using the existing production command deployment script, then restart/deploy the updated bot.
